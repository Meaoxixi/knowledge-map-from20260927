# Zoomable Knowledge Map

一个基于 React + Vite 的纵向研究知识演化地图原型。它使用**固定层级坐标 + 语义缩放 + 时间阶段过滤**，而不是随机力导向布局。

## 功能

- 左侧时间轴：切换 8 月、9 月、10 月学习阶段。
- 语义缩放：缩小时聚焦主干与总结节点；中等缩放展示主题；放大后展示细粒度节点与摘要。
- 节点详情：选择节点查看笔记、标签、上下游连接。
- 分支展开/收起：点击节点旁的 `+ / −` 或右侧操作按钮。
- 关系高亮：选择节点后突出相关节点与边。
- 画布交互：滚轮缩放、拖动平移、全局复位。
- 搜索：按标题、摘要与标签定位节点。
- 深浅主题切换。
- 所有示例内容集中在 `src/data/graphData.js`，组件与数据分离。

## 本地运行

需要 Node.js 18 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的本地地址。

生产构建：

```bash
npm run build
npm run preview
```

## 数据模型

### 节点

```js
{
  id: "data-quality",              // 全局唯一 ID
  title: "数据质量筛选",            // 完整标题
  short: "质量筛选",                // 宏观视图短标签
  type: "detail",                  // root/topic/summary/branch/detail/final
  stage: "oct",                    // aug/sep/oct：最早出现的阶段
  x: 490, y: 1110,                 // 稳定画布坐标
  level: 3,                         // 0 为核心，数字越大越细
  summary: "一句话摘要",
  detail: "详情面板内容",
  tags: ["数据", "评测器"]
}
```

### 连接

```js
{ id: "e1", source: "data", target: "data-quality", label: "细化" }
```

`source` 和 `target` 必须引用已有节点 ID。连接关系表达知识关联，不自动表示时间因果。

## 自定义内容

1. 编辑 `src/data/graphData.js` 中的 `stages`、`nodes` 和 `edges`。
2. 每个节点设置唯一 `id`、最早出现的 `stage`、稳定的 `x/y` 坐标和层级 `level`。
3. 连接只需引用节点 ID。
4. 新增节点类型时，在 `src/App.jsx` 的 `COLORS` 和类型中文名映射中补充样式。
5. 如果节点数量明显增加，建议把坐标规划抽离为专门布局模块，或引入 ELK.js / Dagre 计算分层布局，再将计算结果缓存为稳定坐标。

## 语义缩放规则

规则位于 `src/utils/layout.js`：

- scale < 0.48：全局视图，主要保留核心与总结节点。
- 0.48 ≤ scale < 0.88：主题视图，显示到第二层。
- scale ≥ 0.88：细节视图，显示更细粒度的节点与摘要。

这些阈值可以按实际节点密度调整。当前实现用 SVG 的统一变换控制缩放，并按比例切换信息粒度；如需在超大图谱中实现数千节点，可考虑 Canvas/WebGL 渲染与视口裁剪。

## 时间轴语义

`stage` 表示节点最早出现的阶段。切换阶段时，显示该阶段及之前已经出现的节点，因此早期节点会保留在后续地图中。图谱位置由节点坐标决定，不因切换阶段重新布局。

## 注意

当前数据是为了验证交互的**示意性内容**，并非对世界模型研究现状的权威综述或已验证结论。请为真实研究笔记补充论文、链接、日期、证据和个人判断。
